  1. Recommended for this device

    iPhone and iPad

    Available

    Two ways, both free, no App Store needed. Use one or both.

    1. The app, on your Home Screen

    The full HazeNow, installed from Safari. It works offline and opens like any other app.

    1. Open HazeNow in Safari.
    2. Tap Share, the square with an arrow. On iOS 26, tap ••• first, then Share.
    3. Scroll down and tap Add to Home Screen, then Add.

    Open HazeNow in Safari

    2. A widget, with Scriptable

    A Home Screen and Lock Screen widget. It runs inside Scriptable, a free app by another developer, not by us. Our script is open source, so you can read every line first.

    1. Install Scriptable. It's free on the App Store.
    2. Add the HazeNow widget. On your iPhone, tap the button below and then Download. Open it from Safari's downloads (the arrow in the address bar) and choose Open in Scriptable, or tap Share and pick Scriptable. HazeNow is now in your Scriptable scripts.
    3. Put it on your Home Screen. Long-press an empty spot, tap + (on newer iPhones, Edit then Add Widget), pick Scriptable, choose a size and tap Add Widget. Long-press the new widget, tap Edit Widget and set Script to HazeNow.

    Install Scriptable (free) Add the HazeNow widget

    Lock Screen: long-press the Lock Screen, tap Customize, then Lock Screen. Tap the widget area, pick Scriptable and a shape, then tap it and set Script to HazeNow.

    One area: it shows Singapore island (or your spot, if you let Scriptable use your location). Type an area such as Tampines in the widget's Parameter field to show that area.

    Didn't open in Scriptable? Paste it instead
    1. Tap Copy script below, or open our script, select all and copy.
    2. In Scriptable, tap +, paste, name it HazeNow and tap Done.

  2. Recommended for this device

    Android

    Beta

    Two ways, both free, no Play Store needed. Start with the first. Add the second if you want a widget.

    1. Install from Chrome

    3 taps, no warnings. The full HazeNow in its own window, on your Home Screen. It works offline.

    1. Open HazeNow in Chrome.
    2. Tap ⋮ at the top right, then Add to Home screen (or Install app).
    3. Tap Install.

    Open HazeNow in Chrome

    2. Full app with widget and Quick Settings tile

    Adds Home Screen widgets, a Quick Settings tile and calm band alerts. Android 8 or newer. It doesn't come from the Play Store, so Android checks with you before installing it. That's expected, and it only happens once.

    1. Tap Download for Android below and open the file when it's done.
    2. Android asks whether your browser may install apps. Tap Settings, turn on Allow from this source, then go back.
    3. Tap Install. Google Play Protect may offer to scan the app, which is fine. If it says it doesn't recognise the app, that's because it's new and not in the Play Store: tap More details, then Install anyway. Samsung and Xiaomi phones may run their own check too; choose Install anyway or Continue.

    Download for Android HazeNow-android.apk

    Why the checks? HazeNow is free, and we don't list it on the Play Store yet. The code is open, and every download is built from it.

    Get updates automatically with Obtainium (optional)

    Obtainium is a free, open-source app that installs updates straight from our GitHub releases.

    1. Install Obtainium from its GitHub releases or F-Droid.
    2. On your phone, tap Add to Obtainium below. Or in Obtainium, tap Add app and paste https://github.com/%RELEASES_REPO%.
    3. Obtainium checks for new versions and tells you when one is ready.

    Add to Obtainium

  3. Recommended for this device

    Mac

    Beta

    ● 105 ▲ in your menu bar. Two ways, both free. Pick either one.

    The app

    The reading in your menu bar, with an optional pill beside the notch. macOS 14 or newer. macOS warns you once, because we don't pay Apple to verify it.

    1. Click Download for Mac below. Double-click the zip to unzip it.
    2. Drag HazeNow into your Applications folder, then open it.
    3. macOS says “HazeNow” Not Opened because Apple could not verify “HazeNow” is free of malware. Click Done.
    4. Open System Settings → Privacy & Security. Scroll down to Security. Next to the line “HazeNow” was blocked to protect your Mac, click Open Anyway. The button stays there for about an hour after you tried.
    5. Click Open Anyway again and enter your password. From now on, HazeNow opens normally, up in your menu bar.

    Why the warning? HazeNow is free, and we don't pay Apple's US$99 a year to have it verified. The code is open, so anyone can check it.

    Download for Mac HazeNow-mac.zip

    SwiftBar plugin, no warning

    One small file with the same reading. It runs inside SwiftBar, a free, open-source menu bar app, so macOS doesn't ask.

    1. Install SwiftBar from swiftbar.app, or run brew install --cask swiftbar. Open it and pick a plugin folder.
    2. Download hazenow.2m.py below into that folder.
    3. In Terminal, run chmod +x hazenow.2m.py in that folder. The reading appears in your menu bar.

    Download the plugin hazenow.2m.py

  5. Command line

    Available

    The reading in your terminal, tmux or starship. Needs Node 18 or newer.

    npm i -g %DL%/hazenow-cli.tgz

    Then run hazenow, or hazenow --oneline for ● 105 ▲. hazenow --help lists the rest.

  6. Home Assistant

    Available

    Sensors for PM2.5, band, verdict and NEA's 24-hr PSI, for home and each region.

    With HACS

    1. In HACS, open ⋮ → Custom repositories.
    2. Add the HazeNow integration repository with type Integration, then install HazeNow. (HACS needs the integration's own repository; see the install guide.)
    3. Restart Home Assistant. Go to Settings → Devices & services → Add integration → HazeNow.

    Or by hand

    1. Download the zip below and unzip it into your Home Assistant config folder, so you get config/custom_components/hazenow.
    2. Restart, then add HazeNow under Devices & services.

    Download the integration
